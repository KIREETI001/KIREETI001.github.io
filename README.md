# kireeti001.github.io

My portfolio site, served by GitHub Pages at **https://kireeti001.github.io**.

## How to update it

| I want to… | Edit |
|---|---|
| Change text, add a project, award, role or link | `content.js` |
| Swap a photo | Replace the file in `images/` with one of the same name, or point `cover` / `src` in `content.js` at a new file |
| Update my resume | Replace `resume.pdf` |
| Change the look | `index.html` (styles are at the top) |
| Change behaviour (galleries, detail view) | `app.js`, rarely needed |

You can edit any file directly on github.com (open it → pencil icon → **Commit changes**).
The live site updates about a minute later.

### Ordering
- **Wall of fame:** hackathons with an `event` and `placement` appear here, sorted by placement (1st on the left), newest first within a tie.
- **Projects:** entries with `"featured": true`, sorted by `rank` (1 = leftmost).
- **Experience / Leadership:** sorted by `rank`.

### Images
Keep photos under ~300 KB (around 1600px on the long side, JPEG) so the page stays fast.

### Still to fill in
Search `content.js` for `[` to find placeholders such as `[Your role]`, `[N]` and `[Prize]`.
